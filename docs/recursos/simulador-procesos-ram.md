# Simulador de Procesos y Gestión de RAM

## ¿Qué es?

El simulador de procesos y gestión de RAM es una herramienta que permite observar de manera práctica cómo un sistema operativo administra los procesos y el uso de la memoria RAM.

A través del simulador se pueden crear procesos, asignarles memoria y observar cómo se comportan mientras están en ejecución.

## ¿Para qué sirve?

Esta herramienta permite comprender de una forma más sencilla algunos conceptos relacionados con la administración de procesos y memoria en un sistema operativo.

Entre sus principales funciones se encuentran:

* Crear procesos.
* Asignar memoria RAM a los procesos.
* Visualizar los procesos creados.
* Observar el uso de la memoria.
* Simular la administración de procesos.

## ¿Cómo utilizarlo?

1. Presiona **Abrir Simulador**.
2. Espera a que aparezca la interfaz.
3. Utiliza la opción **Crear proceso**.
4. Ingresa los datos solicitados.
5. Crea el proceso y observa cómo se refleja en el simulador.
6. Revisa el estado de los procesos y el uso de la memoria RAM.
